# Appals

As the Amazon forest is to *Amazon*, the Appalachian Mountains is to my fun backend demo project for creating a Spring Boot server with many different CRUD-styled REST endpoints.

## Getting started

Before running, make sure to run this command first:

```{bash}
./gradlew build
```

To start the server on localhost:8080, run:

```{bash}
./gradlew bootRun
```

## Other Notes

This server uses an H2 database, which will initialize a local database file when you run it for the first time. To reset the database, make sure to delete this file.
